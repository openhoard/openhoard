# clients/

Everything people touch: the web app / phone PWA, the desktop client (tray, quick search,
Company Files drive, background service), and integrations such as an Office add-in and a
Teams bot. Clients talk to the gateway over REST/MCP as allowlisted OAuth clients.

- [`extension/`](extension/README.md): the browser extension (T-1207): save a page, a PDF or a
  selection to your OpenHoard server.
