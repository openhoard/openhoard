# ADR-0010: Web app: React + Vite PWA

- Status: proposed
- Date: 2026-09-23
- Deciders: @RevBooyah
- Related: T-901

## Context

From the OpenHoard Dev Plan (stack decisions). Mainstream; matches OpenClaw's React UI.

## Decision

React with Vite, installable as a PWA for phones.

## Options considered

- **Chosen:** React + Vite PWA
- Next.js
- SvelteKit

## Consequences

Server rendering not needed for an authenticated app.
